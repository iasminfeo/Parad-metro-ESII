# Paradômetro — MVP de monitoramento de tempo parado em roteiros

Engenharia de Software II — PUC Minas — Prof. Sandro Laudares
Equipe: Iasmin Oliveira e Felipe Unsonst

## Como rodar
Não precisa instalar nada. Abra a pasta no VS Code e:
1. Instale a extensão **Live Server** (Ritwick Dey).
2. Clique com o botão direito em `index.html` > **Open with Live Server**.

(Alternativa: dar dois cliques em `index.html` para abrir no navegador.)

## Arquivos
- `index.html`: estrutura da página
- `style.css`: tema azul pastel (claro e escuro)
- `app.js`: dados de exemplo, regras de negócio (RN01 a RN07), telas e persistência

## Observações
- Os dados ficam no localStorage do navegador. Para zerar, use "Restaurar dados de exemplo" em Parâmetros.
- Os perfis (Administrador, Gerente, Motorista) são simulados, sem login.
- As fontes vêm do Google Fonts; sem internet, o sistema usa fontes padrão.
